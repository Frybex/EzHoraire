Optimisation de l'affichage sur Grands Écrans

Sur les grands écrans (écrans 1440p, 4K ou fenêtres très hautes), la grille actuelle s'étire à calc(100vh - 170px). Cet étirement démesuré dilue le contenu : la salle flotte au milieu avec 150px de vide et le professeur est plaqué tout en bas. Voici 5 propositions de refonte fidèles à la direction artistique de l'application (moderne, simple, soft neumorphism) avec la méthode exacte de détection de hauteur.

Proposition 1 · Équilibrée & Pratique (Recommandée)

Grille Plafonnée + Dashboard Inférieur Intelligent

La grille garde sa taille idéale et compacte ; l'espace inférieur accueille 3 widgets dynamiques très utiles.

Principe UX

On fixe un plafond de hauteur maximale (max-height: 540px ou ratio heure ~45px) pour que les cartes conservent leur proportion dorée.

L'espace disponible sous la grille (qui serait autrement un trou vide) est investi dans un Dashboard contextuel (cours en cours, synthèse hebdomadaire, actions rapides).

  • Avantage : Résout 100% du problème de vide sans étirer les cartes.
  • Avantage : Donne une valeur ajoutée forte à l'expérience desktop.
  • Attention : Nécessite de concevoir les 3 widgets du dashboard.

Comment détecter la hauteur ?

/* Détecte un grand écran en hauteur */ @media (min-width: 1024px) and (min-height: 850px) { #horaire-contenu { grid-template-rows: auto minmax(420px, 58vh) auto; height: calc(100dvh - 120px); } .dashboard-bas { display: grid; /* Activé sur grand écran */ } }

Principe UX

Au lieu d'avoir un flex-grow: 1 qui éloigne bêtement la salle du titre, on supprime cet étirement et on profite de l'espace pour enrichir la carte :

  • Badges de salle stylisés avec icône/bâtiment (ex: Salle 2/10E · Étage 2).
  • Micro-avatar et libellé complet du professeur.
  • Indicateur de statut ou durée totale du cours (ex: Séance pratique · 4h).
  • Trame temporelle discrète (repères toutes les heures) pour donner du rythme visuel à la grille.
  • Avantage : L'aspect "grand écran Pro" est superbe et ne semble jamais vide.
  • Avantage : Aucune refonte architecturale : uniquement du CSS et de la mise en page interne.

Comment détecter la hauteur ?

/* Détection par Container Queries ou Media Query */ @media (min-height: 950px) { .ev { gap: 8px; /* Espace naturel et maîtrisé */ padding: 12px 14px; } .ev .es { flex-grow: 0; /* Fini le vide au milieu ! */ background: rgba(0,0,0,.06); border-radius: 6px; } .ev .extra-info { display: flex; /* Révélé uniquement si assez haut */ } }

Principe UX

Plutôt que d'étirer artificiellement 5 jours sur 1200px de hauteur, on empile deux semaines consécutives (Semaine N + Semaine N+1).

Chaque semaine a une hauteur compacte optimale (~240px-280px). L'étudiant voit immédiatement ce qui l'attend la semaine suivante (préparation de rendus, devoirs, examens) sans jamais devoir cliquer sur "Semaine suivante".

  • Avantage : Utilisation exemplaire de la hauteur verticale.
  • Avantage : Immense confort de planification pour les étudiants.
  • Attention : Nécessite de charger les cours de 2 semaines en mémoire (déjà supporté par les données d'EzHoraire).

Comment détecter la hauteur ?

/* Active la double-semaine si la hauteur est suffisante */ @media (min-width: 1024px) and (min-height: 980px) { .vue-quinzaine { display: flex; flex-direction: column; gap: 18px; } }

Principe UX

Les grands écrans sont presque toujours très larges en plus d'être hauts. Plutôt que d'occuper 100% de la largeur avec une grille géante qui s'étire dans tous les sens, on utilise un Split Screen ergonomique :

  • La grille horaire reste centrée à gauche dans des proportions idéales.
  • Un volet latéral permanent exploite toute la hauteur pour afficher la fiche complète du cours cliqué et le PDF officiel en direct.
  • Plus de pop-up qui masque la vue ou de panneau PDF qui écrase violemment la semaine au clic !

@media (min-width: 1400px) and (min-height: 800px) { #horaire-contenu { grid-template-columns: 1fr 340px; grid-template-areas: "week side" "cal side" "foot side"; } }

Principe UX

Cette approche divise la hauteur en deux modes complémentaires :

  • Le tiers supérieur donne la vue macro (la semaine condensée en une bande élégante pour voir où sont les trous).
  • Les deux tiers inférieurs donnent la vue micro (l'agenda déroulé avec chronologie détaillée du jour sélectionné, heure par heure, pause de midi bien visible, statuts clairs).

Cliquer sur un jour dans la barre du haut change instantanément l'agenda du bas.
